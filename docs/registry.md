# Реестр нарушений для сверки

Начальные данные реестра, которые сервис использует в отчётах. Суммы — по памяти составителя, 
**каждую строку нужно сверить с действующей редакцией КоАП РФ**. После сверки внесите правки 
в админке (раздел «Реестр нарушений») и отметьте правило как «Сверено» — отчёты сразу начнут 
показывать новые суммы. Этот файл после этого не обновляется автоматически.

Всего правил: 32. Уверенность: 🟢 высокая — 7, 🟡 средняя — 12, 🔴 низкая — проверить обязательно — 13.
